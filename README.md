# EnterpriseHyperTunnel v2.0.0 (Netty 管道端口复用版)

> **全通用零配置架构**：直接注入 Minecraft 服务端原生 Netty 管道，与游戏主端口 100% 融合共存，**零额外端口占用、零配置、盲传即用**！

---

## 🌟 为什么 v2.0.0 能做到“任何服务器直接丢进去就能用”？

1. **Netty 管道原生共存（0 额外端口占用）**：
   - 彻底不再另外 `bind` 任何新端口；
   - 直接挂载在 Minecraft 现有的主端口（如 `25905`、`25565` 等）上，自动与游戏协议复用；
   - 正常玩家、假人数据包 ➡️ 100% 原样放行给游戏主循环；
   - VLESS-WS / XHTTP 数据包 ➡️ 动态截胡分流至代理转发模块。
2. **完美突破 NAT 映射与防火墙**：
   - 只要你的 Minecraft 游戏能连上，代理节点就必然 100% 能连上（因为走的是同一个外网合法映射端口）！
3. **零外部二进制与极小体积**：
   - 复用 Minecraft 服务端自带的 Netty 运行时，无需额外引入重量级网络库。

---

## 🛠️ 安装方法
直接下载 Release 中的 `enterprise-hyper-tunnel-2.0.0.jar` 放入服务器的 **`mods/`** 文件夹，重启开服即可！
